Record non-overlapping segments: active, app/provider wait, credential acquisition, facilitator probe,
facilitator setup, interruption. Wall duration = sum of segments; active includes thinking and reading UI.
Keep main-task and follow-up clocks separate. Note backtracks, validation resubmissions, help requests,
first hesitation, save/exit, resume, first visible result, examined result and explicit finish.
